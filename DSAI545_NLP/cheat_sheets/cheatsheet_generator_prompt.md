# Reusable Prompt for Generating NLP Cheat Sheets

Copy-paste this into a new chat along with your uploaded lecture PDF:

---

I'm uploading my NLP lecture slides (DSAI 545, Boğaziçi University). Please create a comprehensive `.md` cheat sheet that includes:

1. **Core concepts** — explain each topic covered in the lecture concisely but thoroughly
2. **All formulas** — clearly formatted with notation explained
3. **Step-by-step worked examples** — walk through the key computations from the slides by hand
4. **Key distinctions and exam traps** — things that are easy to confuse or mess up under pressure
5. **Quick reference card** — a compact ASCII box with the most important formulas to memorize
6. **8-10 practice midterm questions** covering easy → hard difficulty, including:
   - Direct computation problems (fill tables, calculate probabilities, etc.)
   - Conceptual/short-answer questions (explain why X works, compare approaches)
   - At least one tricky edge case question
   - Full step-by-step solutions for every question

Format rules:
- Write in `.md` and save as a file I can download
- Use tables for structured data, code blocks for formulas
- Keep explanations concise — I have a math engineering background and work as a data scientist
- Use Python-friendly notation where relevant
- Don't write actual code unless I ask for it
