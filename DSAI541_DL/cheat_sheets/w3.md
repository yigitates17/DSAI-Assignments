# DSAI541 Deep Learning: Lecture 3 Cheat Sheet

## 1. Network Architectures & Terminology
* **Shallow Neural Networks:** Neural networks that contain exactly one hidden layer.
* **Deep Neural Networks:** Neural networks that contain more than one hidden layer.
* **Feedforward Fully Connected Network:** A network where everything in one layer is connected to everything in the next layer, and there are no loops.
* **Pre-activations:** The linear values calculated right before they are passed into the activation function.
* **Activations:** The values produced after passing the pre-activations through the activation function (like ReLU).
* **Hyperparameters:** Choices made before training begins, such as the depth (number of layers, $K$) and the width (number of hidden units per layer, $D_k$). 

## 2. Mathematical Formulation
* **Shallow NN Equation:** A 1-input, 1-output shallow network with ReLU activation ($a[\cdot]$) is formulated as: 
  $$y = \phi_0 + \phi_1 a[\theta_{10} + \theta_{11}x] + \phi_2 a[\theta_{20} + \theta_{21}x] + ...$$
* **Deep NN General Case:** Expressed using matrices and vectors, the transition to the $k$-th hidden layer is:
  $$h_k = a[\beta_{k-1} + \Omega_{k-1}h_{k-1}]$$ 
  where $\beta$ is the bias vector and $\Omega$ is the weight matrix. 
* **Universal Approximation Theorem:** With enough hidden units, a shallow neural network can describe any continuous function on a compact subset of $\mathbb{R}^D$ to arbitrary precision.

## 3. Deep vs. Shallow Networks
* **Depth Efficiency:** While both shallow and deep networks obey the Universal Approximation Theorem, deep networks can do the job with fewer neurons. Shallow networks might require an impractically large number of neurons for some functions.
* **Expressivity:** Deep networks create a significantly higher number of linear regions per parameter than shallow networks.
* **Training Speed:** Deeper models typically require fewer training epochs to converge. 

## 4. Loss Functions & Probabilistic Modeling
* **Maximum Likelihood Criterion:** The process of finding model parameters $\phi$ that maximize the probability of observing the target data $y_i$ given the inputs $x_i$ and the model $f$.
* **Negative Log-Likelihood (NLL):** Multiplying probabilities can result in values too small to represent. To solve this, we take the negative logarithm, turning it into a general minimization problem for finding loss functions: 
  $$\hat{\phi} = argmin_\phi \left[-\sum_{i=1}^{I}\log[Pr(y_i|f[x_i,\phi])]\right]$$
* **Univariate Regression (OLS Loss):** If we assume the target variable's errors follow a normal (Gaussian) distribution, minimizing the NLL yields the Ordinary Least Squares loss: 
  $$L[\phi] = \sum_i(y_i - f[x_i, \phi])^2$$
* **Binary Classification (Binary Cross-Entropy Loss):** For binary targets $y \in \{0,1\}$, we assume a Bernoulli distribution. We apply a sigmoid function to the network's output so it represents a probability between 0 and 1. This results in the loss: 
  $$L[\phi] = \sum_{i} -(1-y_i)\log[1-sig[f[x_i|\phi]]] - y_i\log[sig[f[x_i|\phi]]]$$

## Example Midterm Questions & Step-by-Step Solutions

### **Question 1: Network Capacity and Depth**
Both shallow and deep neural networks satisfy the Universal Approximation Theorem. Explain two distinct mathematical or practical reasons why modern applications (like computer vision and NLP) overwhelmingly prefer Deep Neural Networks over Shallow Neural Networks.

**Step-by-Step Reasoning:**
1. **Recall the definition:** The Universal Approximation Theorem states that even a network with just one hidden layer can approximate any continuous function. 
2. **Identify Reason 1 (Depth Efficiency):** While a shallow network *can* approximate a complex function, it may require an exponentially large number of hidden units to do so, making it impossible to train computationally. Deep networks are "depth efficient," meaning they can represent these complex functions with far fewer total neurons. 
3. **Identify Reason 2 (Regions per parameter):** A deep network ($K > 1$) distributes its trainable parameters across multiple layers, which exponentially increases the number of linear regions (separated by joints) it can create compared to a shallow network ($K=1$) with the exact same number of parameters.
4. **Bonus Reason (Epochs):** Deep models have been empirically shown to fit data faster, requiring fewer epochs during training. 

### **Question 2: Deriving Loss Functions**
Starting from the general Negative Log-Likelihood equation, derive the Ordinary Least Squares (OLS) loss function for a univariate regression problem. Clearly state the statistical assumption required for this derivation. 

**Step-by-Step Reasoning:**
1. **State the Assumption:** For univariate regression yielding OLS, we must assume that the error (residuals) of the target values $y$ follow a Normal (Gaussian) distribution, and that the variance $\sigma^2$ is constant. 
2. **Write the Probability Density Function:** Based on the assumption, the probability is: 
   $$Pr(y_i|f[x_i,\phi],\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\left[-\frac{(y_i-f[x_i,\phi])^2}{2\sigma^2}\right]$$
3. **Start with the NLL Formula:** $$\hat{\phi} = argmin_\phi \left[-\sum_{i=1}^{I}\log[Pr(y_i|f[x_i,\phi])]\right]$$
4. **Substitute the Distribution:** $$\hat{\phi} = argmin_\phi \left[-\sum_{i=1}^{I}\log\left[\frac{1}{\sqrt{2\pi\sigma^2}}\exp\left[-\frac{(y_i-f[x_i,\phi])^2}{2\sigma^2}\right]\right]\right]$$
5. **Expand the Logarithm:** The log of a product is the sum of the logs. $\log(A \cdot \exp(B)) = \log(A) + B$.
   $$= argmin_\phi \left[-\sum_{i=1}^{I}\left(\log\left[\frac{1}{\sqrt{2\pi\sigma^2}}\right] - \frac{(y_i-f[x_i,\phi])^2}{2\sigma^2}\right)\right]$$
6. **Simplify (Drop Constants):** Because we are finding the `argmin` with respect to the network parameters $\phi$, any terms that do not contain $\phi$ act as constants and do not affect the location of the minimum. We can throw away the $\log[\frac{1}{\sqrt{2\pi\sigma^2}}]$ term and the constant denominator $2\sigma^2$.
7. **Final Result:** Eliminating the constants leaves us with the OLS loss function:
   $$\hat{\phi} = argmin_\phi \left[\sum_{i=1}^{I}(y_i-f[x_i,\phi])^2\right]$$

### **Question 3: Forward Pass Calculation**
You are given a shallow neural network with 1 input $x$, 1 output $y$, and 1 hidden layer containing 2 neurons. The activation function is ReLU ($a[z] = \max(0, z)$). The model is defined as:
$$y = \phi_0 + \phi_1 a[\theta_{10} + \theta_{11}x] + \phi_2 a[\theta_{20} + \theta_{21}x]$$

Given the following trained parameter values:
* $\phi_0 = 1.5$
* $\phi_1 = 2.0, \quad \phi_2 = -3.0$
* $\theta_{10} = -2.0, \quad \theta_{11} = 1.0$
* $\theta_{20} = 4.0, \quad \theta_{21} = -1.0$

Calculate the final output $y$ if the input is $x = 3$.

**Step-by-Step Reasoning:**
1. **Calculate Pre-activation for Neuron 1:** $z_1 = \theta_{10} + \theta_{11}x$
   $z_1 = -2.0 + (1.0)(3) = 1.0$
2. **Calculate Activation for Neuron 1:** $h_1 = ReLU(z_1)$
   $h_1 = \max(0, 1.0) = 1.0$
3. **Calculate Pre-activation for Neuron 2:** $z_2 = \theta_{20} + \theta_{21}x$
   $z_2 = 4.0 + (-1.0)(3) = 1.0$
4. **Calculate Activation for Neuron 2:** $h_2 = ReLU(z_2)$
   $h_2 = \max(0, 1.0) = 1.0$
5. **Calculate Final Output:** Multiply activations by their weights and add the bias $\phi_0$.
   $y = \phi_0 + \phi_1 h_1 + \phi_2 h_2$
   $y = 1.5 + (2.0)(1.0) + (-3.0)(1.0)$
   $y = 1.5 + 2.0 - 3.0$
   **$y = 0.5$**
